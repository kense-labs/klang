# K 语言性能与内存基准总结

本页基于 [2026 年 10 月 16 日全量基准报告](../../bench/summary.md)，汇总 K 在 16 项大型工作负载下对比**惯用 C++（Idiomatic C++）**、**专家优化 C++（Expert C++）**以及**最佳安全 Rust（Best Safe Rust）**的实测结果。完整分项耗时、内存数字与测量方法请查阅英文原始数据：[详细结果表](../../bench/results.md) · [基准设计说明](../../bench/design.md)。

---

## 总体结论（16 项大型基准几何平均）

在 MSVC 与 Clang 两种 C 编译器后端上开启 `-O3 --lto --cpu=native` 后，K 的几何平均表现如下：

| 对比对象 | 运行速度加速比（MSVC / Clang） | 峰值内存优势（K 更省内存） |
|---|---|---|
| **对比惯用 C++** | **3.51x / 3.54x** | 内存减少 **1.95x** |
| **对比专家优化 C++** | **1.24x / 1.26x** | 内存减少 **1.32x** |
| **对比最佳安全 Rust** | **1.13x / 1.19x** | 内存减少 **1.25x** |

> **测量说明**：以上均为全进程端到端计时（包含输入生成、结构构造、核心计算与析构退出），在大规模数据尺寸下预热 2 次后取 3 次运行的最佳值。

## 核心性能来源

### 1. 编译期无检查图遍历与内核（`checkfree fn`）
- 在 `graph` 基准中，图顶点下标被编码为类型化索引 `u32 in dist`，CSR 前缀偏移使用 `u32 upto out`。合法性在构图入口统一验证，`checkfree fn bfs` 确保遍历内循环**一条运行期越界检查都不保留**。
- 大尺寸 CSR 实测耗时为 **699 / 617 ms**（C++ 为 784 / 761 ms，Rust 为 811 ms），速度领先同后端 C++ **1.12x / 1.23x**，领先安全 Rust **1.16x / 1.32x**。

### 2. 紧凑内联表示与变长枚举
- **`records`**：比 Rust 快 **2.02–2.26x**，且峰值内存仅为 Rust 的 **1/3.98**。K 的可变模式枚举直接按当前记录真实载荷（含内联短文本）紧致排布，消除了通用堆节点与指针追踪开销。
- **`interp`**：比 Rust 快 **1.29–1.41x**，内存减少 **2.04x**。
- **`sexp`**：峰值内存比 Rust Arena 分配版本省 **2.43x**，比 C++ 独立所有权节点省 **5.04x**。

### 3. 明确存在的弱项与边界
- 并非所有负载都由 K 领先：`calc` 中 K（481 / 491 ms）略慢于 Rust Arena（436 ms）；`lru` 与 `scene` 在 MSVC 下落后于 Rust，在 Clang 下与 Rust 持平或微弱领先。
- 在图像处理 `blur` 中，单纯消除越界检查并不能自动消除 MSVC 对扁平索引的后端优化差异（Row-slice 写法则可在 MSVC/Clang 下均稳定跑在 ~269–298 ms，与 Rust 的 299–300 ms 持平）。
